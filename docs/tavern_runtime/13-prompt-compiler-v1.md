# Prompt Compiler v1

The compiler accepts already-resolved `PromptSource` values and produces a provider-neutral `CompiledPrompt` plus a content-free `PromptCompileTrace`. It neither reads SQLite nor invokes a Provider, World Info scanner, RAG retriever, Memory engine, macro engine, regex runtime or Generation Runtime. Upstream application orchestration collects sources, compiles once, then starts a generation with a future Driver/Provider adapter. The v13 schema and archive format are unchanged.

Phase 1 SillyTavern research (`docs/tavern_next/06-prompt-pipeline.md` in the porting-study worktree) established that fixed string concatenation is inadequate: examples, notes, World Info and history have distinct placement and budgets; absolute history depth and Continue prefill matter; a mandatory overflow must fail. This implementation adopts those placement and accounting ideas, not SillyTavern's mutable hooks or provider wire messages.

Character, Persona, Scenario, Example Dialogue, World Info, Memory and RAG arrive as typed sources with stable origin references. World Info activation and retrieval happen upstream. A future reviewed macro/regex transform may run before source submission; no imported script executes inside the compiler. The application must preserve the transformed source's original origin and add transform provenance in a future trace layer.

`PromptHistoryAssembler` consumes the Foundation `TavernTranscriptProjection`, never raw Turn rows. Normal mode promotes the latest player Turn to a required current-input source. Regenerate ends history before its target answer and promotes the preceding player Turn, inserting it at its original position relative to any other same-round speakers; it never includes the old target Alternative. Continue ends history before the target answer and emits that selected answer as a required assistant-like continuation segment. The adapter may map that segment to a provider prefill or equivalent continuation facility, but must not silently turn it into a new user message. Branch-frozen Alternative selection is inherited from the projection.

Known limits: no exact provider tokenizer, no provider request digest, no persisted Attempt-to-prompt reference, no media bytes, no tool execution, and no prompt-transform runtime. A future orchestration layer can hold the compiled result and attach a deterministic digest/reference to Generation Attempt metadata; v13 already has Attempt metadata, but v1 does not write to it.
